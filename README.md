# 미니골프 ⛳

끌었다 놓아 공을 쳐서 홀에 넣는 게임. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `courses.js` + `game.js`)입니다.

- **조작**: 화면 아무 데나 누르고 **치고 싶은 방향의 반대쪽으로 끌었다 놓는다**(슬링샷). 많이 끌수록 세게(코스 단위 95 에서 100%). 끄는 동안 화살표와 힘 고리가 보이고, **🎯 보조선**을 켜면 벽에 튕기는 길까지 점선으로 미리 보여 준다(2.4초치). 처음 누른 곳까지 되돌리면 취소
- **물리** (`logic.js`): 고정 간격 1/240초. 속도는 거리에 비례해 줄어들고(잔디 1.15 · 모래 5.2 · 얼음 0.5), 선분 벽에는 반발 0.82 로 튕긴다. 힘 100% 에서 잔디로 약 450 단위를 굴러간다. 홀(반지름 11) 위를 지나가는 공이 초속 300 보다 느리면 들어가고, 빠르면 그냥 지나간다. 물에 빠지면 1타를 더하고 친 자리로 돌아간다. 8타를 쳐도 못 넣으면 그 홀은 8타로 끝
- **장애물**: 벽(각도 있는 벽 포함) · 🏖️ 모래 · 🧊 얼음 · 💦 물 · ➡️ 가속 패드 · 🌀 돌아가는 바람개비 · 왔다 갔다 하는 막대. 움직이는 장애물은 시간만으로 위치가 정해져서 같은 샷이면 결과도 같다 (벽과 같은 방식으로 부딪히고, 움직이는 속도만큼 공에 힘을 준다)
- **코스 18홀**: 🌱 초록 코스(쉬움, 벽·모래·연못·얼음) 9홀, 🌋 모험 코스(어려움, 바람개비·막대·얼음 다리·가속 패드·좁은 다리·열리는 문) 9홀. 홀마다 파(기준 타수)가 있다
- **점수**: 홀인원 · 알바트로스 · 이글 · 버디 · 파 · 보기 · 더블 보기. ⭐ 파보다 적으면(홀인원 포함) 3개, 파면 2개, 그보다 많으면 1개. 코스를 끝내면 **스코어카드**(홀별 타수·합계·파 대비)가 나온다. ☰ 에서 아무 홀이나 골라 할 수 있다
- 홀별 최고 타수는 `minigolfBest`, 코스 합계 최고는 `minigolfCourse_<코스>`, 로비에는 모은 별 수(`minigolfStars`)가 보인다

규칙과 물리는 `logic.js`(화면 없이 Node 로 시험), 코스는 `courses.js`, 화면·입력·소리는 `game.js`.
**모든 홀은 풀 수 있고 파가 공정하다**: `node tools/solve.js` 가 홀마다 빔 탐색(각도 4° · 힘 6단계 · 움직이는 장애물은 기다리는 시간까지)으로 가장 적은 샷 순서를 찾아 `solutions.js` 에 쓰고, 파는 그 타수 + 1 (움직이는 장애물이 있으면 최대 +2)로 맞췄다. 코스를 고치면 다시 돌린다.
시험은 `node --test`: `test/logic.test.js`(마찰로 멈추는 거리 · 벽 튕김 · **최고 속도로 모든 각도를 쳐도 벽을 뚫지 않음** · 모래/얼음/물/가속 · 홀 들어감과 지나침 · 8타 · 입력 검사 · 움직이는 장애물 · 같은 샷은 같은 결과 · 미리 보기가 실제와 같음 · 이름·별 · 모든 홀의 모양(출발·홀이 벽/물에서 떨어짐)과 저장된 풀이로 실제로 홀인되는지·파가 공정한지).
